# ⛧ Neon-Banner ⛧

**Créé par 𝐕𝟒𝐍𝐓𝐄𝐒𝐒 | Label : REQUIEM AURA**

Un créateur de bannière Termux personnalisé, inspiré de Dragon Banner Maker Pro, mais avec l'identité du Cartel.

## 🎭 Fonctionnalités
- Artwork : Dragon, Tux, Vader, Chacal, etc.
- Nom et tagline personnalisables (par défaut : 𝐕𝟒𝐍𝐓𝐄𝐒𝐒 / REQUIEM AURA).
- Couleurs : Rainbow, Red, Green, Cyan, Magenta, Yellow, Blue, White.
- Bloc de démarrage automatique dans `~/.bashrc`.
- Désinstallation propre.

## 🚀 Installation
```bash
git clone https://github.com/redmayneedie-cyber/Van-ban.git
